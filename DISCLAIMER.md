# Disclaimer

**All information provided in this repository and the resulting web application is for
authorised security testing, education, and defensive purposes only.**

This project is a **reference**. It documents publicly-available commands, tools, techniques,
vulnerabilities (with public CVE identifiers), and mitigations. It contains **no exploit
payloads, no malware, and no offensive infrastructure**.

## Acceptable use

You may use this project to:

- Learn how Linux distributions, security tools, and known vulnerability classes work.
- Prepare for and perform **authorised** penetration tests, red-team engagements, purple-team
  exercises, CTFs, and lab-based training.
- Design and validate **defensive** controls, detections, and incident-response procedures.
- Teach or study cybersecurity in a classroom, workshop, or self-study setting using isolated labs
  such as your own virtual machines, TryHackMe, Hack The Box, PortSwigger Web Security Academy,
  or the OWASP-provided intentionally-vulnerable applications.

- Access, disrupt, degrade, or otherwise interfere with any computer system, network,
  application, account, device, or data **without explicit, prior, written authorisation** from
  the owner and/or operator of that resource.
- Violate any applicable law, including but not limited to the U.S. Computer Fraud and Abuse Act
  (CFAA, 18 U.S.C. § 1030), the U.K. Computer Misuse Act 1990, the E.U. Directive 2013/40/EU on
  attacks against information systems, Canada's Criminal Code § 342.1, Australia's Cybercrime Act
  2001, and equivalent legislation in any jurisdiction that applies to you or your target.
- Violate the terms of service, acceptable-use policy, or bug-bounty program scope of any
  service, platform, or infrastructure provider.
- Cause harm to individuals, organisations, or the public.
