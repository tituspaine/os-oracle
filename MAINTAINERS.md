# Maintainers

> Maintainers steward OS Oracle as an **authorized-use, offline-first security knowledge platform**. Maintainers are expected to protect both technical quality and ethical boundaries.

## Core maintainers

| GitHub | Role | Areas |
| --- | --- | --- |
| `@tituspaine` | Lead maintainer / founder | Project direction, code review, releases, security decisions, content moderation |

Additional maintainers may be added here as the project grows.

## Responsibilities

Maintainers are responsible for:

- **Code review** — reviewing changes for correctness, schema fit, and maintainability.
- **Releases** — determining when the repository is ready to tag, publish, and document a release.
- **Security** — triaging private vulnerability reports and coordinating fixes.
- **Content moderation** — rejecting content that crosses ethical or legal boundaries.
- **Quality control** — ensuring new entries are sourced, realistic, and clearly framed for authorized use only.

## Contact

Use one of the following channels:

- **General project issues:** GitHub Issues
- **Sensitive codebase vulnerabilities:** GitHub Security Advisories
- **If private reporting is unavailable:** open a minimal issue titled `SECURITY: contact request` with no technical details

See [`SECURITY.md`](./SECURITY.md) for the full reporting policy.

## How to become a maintainer

Maintainer status is granted by the lead maintainer based on sustained, high-trust contribution.

Typical expectations:

- a track record of accurate, respectful, source-backed contributions
- consistent review participation
- demonstrated understanding of the project's ethics and safety boundaries
- ability to evaluate both content quality and repository health
- willingness to moderate unsafe or out-of-scope submissions

There is no automatic promotion path. Maintainer access is an earned trust role, not a contribution counter.

## Emeritus maintainers

Use this template when recognizing former maintainers:

```md
## Emeritus

- `@username` — former maintainer; recognized for contributions to [area], active [years]
```

Emeritus status is honorary and does not imply active review or release authority.
