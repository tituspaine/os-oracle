## [1.0.0] - 2025-07-01

### Added

- Initial offline-first OS Oracle release.
- CLI entrypoint for searching commands, playbooks, distros, and walkthroughs.
- Static data model for Kali tools, Linux distros, playbooks, and walkthroughs.
- GitHub Actions workflows for CI, docs, release, and security automation.
- Initial contributor, conduct, disclaimer, and security documentation.

### Changed

- Established the repository as a static, source-controlled knowledge platform rather than a dynamic service.

### Fixed

- Initial packaging and build output structure for `dist/cli.js` and bundled data JSON.

### Security

- Added explicit authorized-use framing and private vulnerability reporting guidance.

### Removed

- None.
