What is OS Oracle?

OS Oracle is a completely free, open-source ethical hacking reference platform for security professionals, penetration testers, and ethical hackers worldwide.

Everything is bundled offline - no internet required. Just install once and access 1M+ commands from your terminal.

Quick Start

Installation

npm install -g os-oracle

Basic Commands

os-oracle search "sql injection" os-oracle tools os-oracle tool nmap --commands os-oracle playbooks os-oracle distro ubuntu os-oracle bookmark add nmap os-oracle bookmarks

Commands Reference

  • os-oracle search <query> - Search all content
  • os-oracle tools - List all Kali tools
  • os-oracle tool <name> --commands - View tool commands
  • os-oracle playbooks - List attack playbooks
  • os-oracle playbook <slug> - View playbook details
  • os-oracle distros - List Linux distros
  • os-oracle distro <name> - View distro commands
  • os-oracle bookmark add <item> - Save bookmark
  • os-oracle bookmark list - View bookmarks
  • os-oracle history - View search history
  • os-oracle offline - Confirm offline capability
