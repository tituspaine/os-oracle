⬇️Installation

npm (recommended)

terminal
npm install -g os-oracle
Requires Node.js 18+ or Bun

Bun

terminal
bun install -g os-oracle

Build from source

terminal
git clone https://github.com/tituspaine/os-oracle.git cd os-oracle npm install npm run build:cli npm link # makes 'os-oracle' available globally

Quick test

terminal
os-oracle version os-oracle tools os-oracle search "port scan"

📋Command Reference

Search

CommandDescription
os-oracle search <query>Search across all data (tools, distros, playbooks, errors)
os-oracle search <query> --type toolsFilter by type: tools, distros, playbooks, walkthroughs

Kali Tools

CommandDescription
os-oracle toolsList all Kali tools with categories
os-oracle tools --category <cat>Filter by category (e.g. "Information Gathering")
os-oracle tool <name>Show full detail for a tool (commands, flags, examples, errors)

Linux Distros

CommandDescription
os-oracle distrosList all Linux distributions
os-oracle distros --family <fam>Filter by family: debian, rhel, arch, suse, alpine, gentoo…
os-oracle distro <name>Show full distro reference (package manager, commands, errors)

Playbooks & Walkthroughs

CommandDescription
os-oracle playbooksList all security playbooks
os-oracle playbooks --category <cat>Filter by category: Web, Network, Active Directory…
os-oracle playbook <slug>Show full playbook with steps and commands
os-oracle walkthroughsList all narrated walkthroughs
os-oracle walkthrough <slug>Show step-by-step walkthrough with expected output

Bookmarks & History

CommandDescription
os-oracle bookmark add <type> <slug>Bookmark a tool, distro, playbook, or walkthrough
os-oracle bookmark remove <slug>Remove a bookmark
os-oracle bookmarksList all saved bookmarks
os-oracle historyShow recent command history
os-oracle history clearClear command history

Config & Utility

CommandDescription
os-oracle configShow current configuration
os-oracle config set <key> <val>Set config (e.g. color=true, pageSize=30)
os-oracle config resetReset to defaults
os-oracle offlineShow offline status and data freshness
os-oracle versionShow version and data info

🤝Contributing

OS Oracle is open source and welcomes contributions. To add commands, fix errors, or improve documentation:

Contributing workflow
git clone https://github.com/tituspaine/os-oracle.git cd os-oracle npm install # Edit data files in src/data/ # Add tools to: src/data/kali-extra3.ts # Add distros to: src/data/distros.ts # Add playbooks to: src/data/playbooks-extra.ts # Add walkthroughs to: src/data/walkthroughs.ts # Regenerate JSON npm run generate:data # Submit PR

See CONTRIBUTING.md for full guidelines.
