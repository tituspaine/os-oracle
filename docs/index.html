npm install -g os-oracle
os-oracle

From Source

git clone https://github.com/tituspaine/os-oracle.git
cd os-oracle
npm install
npm run build
npm start

Docker

docker run -it tituspaine/os-oracle

Essential Commands

Search Everything

  • os-oracle search "nmap" - Full-text search
  • os-oracle search "sql injection" --filter playbook - Search by type
  • os-oracle search "privilege escalation" --limit 10 - Limit results

Browse Tools

  • os-oracle tools - List all Kali tools
  • os-oracle tool nmap - View tool details
  • os-oracle tool nmap --commands - Show all commands

Attack Playbooks

  • os-oracle playbooks - List all playbooks
  • os-oracle playbook sql-injection - View playbook details
  • os-oracle playbook xss - XSS attack guide

Linux Distributions

  • os-oracle distros - List supported distros
  • os-oracle distro ubuntu - Ubuntu commands
  • os-oracle distro kali --search firewall - Search in distro

Bookmarks & History

  • os-oracle bookmark add nmap - Save bookmark
  • os-oracle bookmark list - View bookmarks
  • os-oracle history - View search history
