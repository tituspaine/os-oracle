# RESOURCES

> ⚠️ All resources and techniques are for authorized, legal security testing only.
>
> Use these materials only in labs, training environments, or with explicit written permission from the system owner.

OS Oracle is offline-first, but this page lists reputable public resources worth syncing, bookmarking, or consulting when you have connectivity.

## Quick Study Bundles by Goal

### If you are learning web app testing

Start with [PortSwigger Web Security Academy](https://portswigger.net/web-security), [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/), [HackTricks](https://book.hacktricks.xyz), [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings), and labs like [DVWA](https://dvwa.co.uk) or [WebGoat](https://owasp.org/www-project-webgoat/).

### If you are learning Active Directory

Start with [Hack The Box](https://www.hackthebox.com), [TryHackMe](https://tryhackme.com), [BloodHound](https://github.com/BloodHoundAD/BloodHound), [Impacket](https://github.com/fortra/impacket), [Responder](https://github.com/lgandx/Responder), and [Hacking Articles](https://www.hackingarticles.in).

### If you are learning reverse engineering or exploit dev

Start with [Ghidra](https://ghidra-sre.org), [pwndbg](https://github.com/pwndbg/pwndbg), [ROP Emporium](https://ropemporium.com), [OpenSecurityTraining2](https://opensecuritytraining.info), and [pwn.college](https://pwn.college).

### If you are learning blue team / DFIR

Start with [CyberDefenders](https://cyberdefenders.org), [Blue Team Labs Online](https://blueteamlabs.online), [Autopsy](https://www.autopsy.com), [Volatility](https://volatilityfoundation.org), [Velociraptor](https://docs.velociraptor.app), and [The DFIR Report](https://thedfirreport.com).
