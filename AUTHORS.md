## How to get added

If you submit an accepted PR, you are part of the contributor community.

For formal listing updates in this file:

- open or include a PR that updates `AUTHORS.md`, or
- ask a maintainer to add you during release or docs housekeeping

The practical default for this project is simple: **submit a meaningful PR and you're eligible to be added**.

## Attribution principles

- Contributions should remain attributable through Git history and pull requests.
- Maintainers may group contributors by release, role, or sustained impact as the project grows.
- This file recognizes human contributors; it does not replace Git history.
